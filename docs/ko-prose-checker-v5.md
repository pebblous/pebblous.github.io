## 0-1. 경동사란 무엇인가 — 그리고 우리는 아직 아무것도 결정하지 않았다

**경동사(輕動詞, light verb)**란 그 자체로는 뜻이 거의 비어 있고, 앞에 붙은 **서술성 명사**가
의미를 다 지고 가는 동사를 말한다. "가볍다"는 이름은 의미 부담이 가볍다는 뜻이다.

> "품질 검사를 **수행한다**" — 의미는 '검사'에 있고, '수행한다'는 문법적 껍데기다.
> 같은 말을 "품질을 **검사한다**"로 쓰면 껍데기가 사라진다.

한국어에서 흔한 경동사는 **수행·실행·제공·진행·시행·부여**쯤이다.

### ⚠️ 결정 이력 — 없다

**우리는 경동사를 피하기로 결정한 적이 없다.** 출처를 정확히 적으면 이렇다.

| 항목 | 사실 |
|---|---|
| 어디서 나온 조항인가 | **Microsoft 한국어 스타일 가이드**의 "경동사 '수행·실행·제공' 금지" |
| 라이선스 | **독점.** 인용만 가능하고 규칙을 옮겨 쓸 수 없다 |
| 우리 채택 여부 | **없음.** 조사 단계에서 "유용하다"고 평가한 것이 전부 |
| 실측 뒷받침 | 약하다. 위 표대로 대부분이 정상 용법이다 |

초안 첫 판에서 이를 S2(자동 교정)에 올린 것은 **근거를 앞지른 판단이었다.**

### 결론 — 규칙이 아니라 도구로 둔다 (2026-08-01 JH 결정)

> 경동사 방지는 합리적인 제안이되, **완강히 지킬 규칙은 아니다.** 다만 거부감이 드는
> 경동사 사례는 분명히 있을 것이므로, 지식은 문서에 저장해 두고 필요할 때 "경동사 제거"를
> 요청할 수 있게 한다.

이 결정에 따라 경동사는:

- **상시 채점 항목(T12)에서 뺀다.** 점수에 들어가지 않고, 자동 교정도 하지 않는다
- **`--light-verbs` 요청 시 도는 도구로 남긴다** (§1-1)
- 부를 때 판단이 서도록 **판별 기준과 실사례를 문서가 보유한다**

판단 유보를 규칙 없음으로 두지 않고 **"요청 시 실행"이라는 상태로 명시**하는 것이 요점이다.
나중에 거부감이 반복되는 유형이 쌓이면 그때 (가) 표준에서 등급을 매긴다.

## 1. T12 신설 — 실측 번역투 (하위 5종)

기존 T7 '번역투'는 고전 목록("에 있어서", "되어진")을 본다. 실측 결과 그건 **이미 거의 깨끗하다**
(304편에서 이중 피동 1건, "에 있어서" 4건). 정작 새는 것은 아래 다섯이고, 지금 항목이 없다.

T7은 그대로 두고 **T12를 신설한다.** T7은 고전 번역투, T12는 현행 번역투로 역할을 나눈다.

| 코드 | 패턴 | 신호 | 교정 방향 | 등급 |
|---|---|---|---|---|
| T12a | **명사화 "~하는 것"** | "측정하는 것이 중요하다" | 동사로 되돌린다 → "측정이 중요하다" / "측정해야 한다" | S2 |
| T12b | **격조사 겹침** | 에서의·로의·으로의·로서의 | 절로 푼다 → "계층에서의 구현" → "계층에서 어떻게 구현하는가" | S2 |
| T12c | **목적 "~기 위해"** | 한 문단에 2회 이상 | "~하려고", "~하도록", 또는 두 문장으로 분리 | S3 |
| T12d | **무생물 복수 '들'** | 데이터들·모델들·문제들 | 대부분 삭제. 한국어는 복수를 표시하지 않는 것이 기본 | S3 |

**경동사는 T12에 넣지 않는다.** 상시 채점 항목이 아니라 **요청하면 도는 도구**로 §1-1에 따로
둔다. 근거는 §0-1 — 채택 결정이 없고 실측이 규칙을 지지하지 않는다.

**과·와는 제외한다.** "ground truth와의 비교"는 어색하지만 정상 범위이고, `인과의`처럼
낱말 내부가 걸리는 오탐이 나온다. 잡을 값이 비용을 넘지 못한다.

## 1-1. 요청 시 실행 — 경동사 정리 (on-demand)

호출: `ko-prose-humanizer <파일> --light-verbs`

상시 점수에 넣지 않는다. **부를 때만 돈다.** 다만 부르면 판단이 서도록, 아래 기준과 사례를
문서가 갖고 있는다.

### 판별 3단 — 이 순서로 물어야 오탐이 안 난다

**① 목적어 명사에 '-하다'를 직접 붙일 수 있는가?**

붙지 않으면 경동사가 아니다. 여기서 대부분이 걸러진다.

| 목적어 | '-하다' | 판정 |
|---|---|---|
| 방어 · 분류 · 검사 · 검증 | 방어하다 · 분류하다 ○ | 경동사 후보 |
| 레버리지 · 커넥터 · 근거 · 정보 | 레버리지하다 ✗ | **정상.** 손대지 않는다 |
| 코드 · 알고리즘 · 요청 | 코드하다 ✗ | **정상** |

**② '-하다'가 붙어도, 그 동사가 실질 의미를 더하는가?**

더하면 남긴다. 특히 **규모·완수·실제 집행**의 뉘앙스일 때다.

- "이틀에 약 700건의 실험을 **수행했다**" — '수행'이 *실제로 다 돌렸다*를 담는다. 남긴다
- "ADMT 서비스를 **제공하고**" — 사업적 공급이라는 실질 뜻. 남긴다
- "분석 코드를 **실행하고**" — 컴퓨터 실행. 남긴다

**③ 관형절 안인가?**

관형절이면 손대지 않는다. 줄이면 수식 관계가 무너진다.

- "동등한 작업을 **수행하는** 사람" — '수행하는'을 빼면 **"동등한"이 수식할 데를 잃는다**
- "어떤 기능을 **수행하는가**" — 관용구

### 실사례 — 세 단계를 통과한 것만 (실측 40편)

목적어가 직결된 구문 38건 중 실제로 손댈 만한 것은 **7건**이었다.

| 전 | 후 | 왜 |
|---|---|---|
| 7가지 취약점 패턴 각각에 **구조적 방어를 제공한다** | …**구조적으로 방어한다** | 방어=서술성 명사, '제공'이 비었다 |
| 인간·AI 텍스트를 학습하여 **이진 분류를 수행한다** | …**이진 분류한다** | 분류하다가 자연스럽다 |
| 의미론적 **중복 제거 및 데이터 혼합을 수행한다** | **중복을 제거하고 데이터를 섞는다** | 명사 두 개를 '수행'이 억지로 묶었다 |
| 정기적 **기술 검사를 수행한다** | 정기적으로 **기술을 검사한다** | 부사 자리가 살아난다 |
| 마지막으로 **교차 검증을 수행했다** | 마지막으로 **교차 검증했다** | 그대로 붙는다 |
| 39회에서 **리워드 해킹을 수행했음** | 39회에서 **리워드 해킹을 했음** | '수행'이 과하다 |
| 메모리 **삭제 동작을 제공하지만** | 메모리를 **삭제할 수 있지만** | '동작을 제공'은 영어 직역 냄새 |

**남긴 31건**은 ①~③에 걸렸다. 비율로 보면 **후보의 8할이 정상**이다.

> ⚠️ 이 기준으로도 **절대 우위는 안 나온다.** 위 7건조차 원문이 틀린 게 아니라,
> 문장을 짧게 가져갈 자리면 오른쪽이 낫다는 정도다. 그래서 상시 항목이 아니다.

## 2. 심각도 3등급 — 무엇을 자동으로 고치고 무엇을 보고만 하는가

지금 스킬은 11종을 평면으로 놓고 총점만 낸다. 그래서 **치명적 결함과 취향 차이가 같은 무게**다.

| 등급 | 정의 | 처리 |
|---|---|---|
| **S1** | 독자가 뜻을 **오해**한다. 중의성, 사실 불일치, 격 충돌 | **자동 교정 금지 · 반드시 보고.** 사람이 읽고 판단 |
| **S2** | 글이 **어색**하다. 읽히긴 하나 번역기 냄새 | 점수 무관 자동 교정 |
| **S3** | **취향**이다. 사람도 쓴다 | 빈도 임계 초과 시에만 보고. 자동 교정 안 함 |

기존 11종의 재배치:

| 등급 | 항목 |
|---|---|
| S1 | (신설 T13 중의성) · T11 자사 점프 · T10 정보 구조 |
| S2 | T1 줄표 · T4 메타 예고문 · T7 고전 번역투 · **T12a 명사화 · T12b 격조사 겹침** |
| S3 | T2 종결 · T3 상투 비유 · T5 영어 병기 · T6 볼드 · T8 수치 · T9 병렬 · **T12c ~기 위해 · T12d 복수 '들'** |
| — | **경동사** — 등급을 매기지 않는다. 상시 항목이 아니라 `--light-verbs` 요청 시 도는 도구(§1-1) |

> **S1이 자동 교정 금지인 이유.** "재는 자"를 기계가 고치면 '자'를 무엇으로 바꿔야 하는지
> 문맥을 모른 채 찍는다. 오해를 다른 오해로 바꾼다. S1은 **찾아서 보고**하는 것까지가 기계의 몫이다.

## 3. 변경률 게이트 — 폭주를 세운다

지금은 교정이 글의 절반을 바꿔놔도 세우는 장치가 없다.

```
변경률 = (수정된 문장 수) / (본문 전체 문장 수)

< 30%   정상 진행
30~50%  ⚠️ 경고 — 전후 대조표를 전량 출력하고 사용자 확인을 받는다
≥ 50%   ⛔ 중단 — 교정본을 쓰지 않는다. 진단만 출력하고 종료
```

50%에서 중단하는 근거: 그 정도면 문체 교정이 아니라 **다시 쓴 글**이다. 스킬의 제1 원칙
("내용이 아니라 질감을 고친다")을 이미 넘었다는 신호이므로, 결과를 내놓는 것 자체가 위반이다.

추가로 **불변식 검사**를 교정 후 강제한다. 하나라도 어긋나면 중단:

| 검사 | 방법 |
|---|---|
| 수치 보존 | 전·후에서 숫자 토큰 집합이 동일 |
| 링크 보존 | `href` 값 집합이 동일 |
| 인용문 보존 | 따옴표 안 문자열이 동일 |
| 구조 보존 | `<h2>`·`<h3>` 개수와 순서가 동일 |

## 4. T2 개정 — "것이다"를 단독 신호에서 뺀다

현행 검출:

```bash
grep -cE "이다\.|점이다\.|사실이다\.|것이다\." "$FILE"
```

실측상 "것이다" 종결은 **사람이 AI보다 2배 많이 쓴다.** 이 grep은 사람 글을 AI 글로 오판한다.
"~를 통해"도 같다 — 비번역 한국어가 번역문보다 2배 많이 쓴다. 통념이 실증으로 기각됐다.

개정: **단일 낱말 빈도로 T2를 판정하지 않는다.** 종결 어미의 **다양도**를 본다.

```python
# 문장 종결 3~4음절을 모아 분포를 본다.
# 최빈 종결이 전체의 40%를 넘으면 T2 신호. 개별 낱말은 신호가 아니다.
```

이렇게 하면 "것이다"를 많이 쓰되 종결이 고르게 섞인 사람 글은 통과하고,
종결이 한 형태로 쏠린 글만 걸린다. 잡으려던 것이 원래 그것이었다.

- **`으로의` 40건** 중 13건은 `앞으로의`(부사 + 의)라 오탐이고, 나머지 23건은
  "A에서 B로의 전환"이라는 **방향 관용**이다.
- **`로서의` 20건**은 전부 자격을 나타내는 정상 표현이다 — "재무 분석가로서의 실력",
  "설계 도구로서의 모델". **하나도 고칠 것이 없었다.**
- **`기업들` 79건**은 조직 = 사람 집합이라 복수가 자연스럽다.
- **`데이터들` 6건**도 전부 개별 항목을 가리킨다 — "이 데이터들이 모여 만든 분포".

### 11-2. 무엇이 잘못됐나 — '실측'의 뜻이 달랐다

v5 문서 §1은 T12를 이렇게 소개했다.

> "T12 신설 — **실측 번역투 (실측으로 확인된 것만)**"

**그 '실측'은 빈도 계산이었지 문맥 정독이 아니었다.** 40편에서 몇 건 나오는지만 세고,
그것이 실제로 문제인지는 **한 건도 읽지 않았다.** 그러고는 "실측으로 확인했다"고 적었다.

§10에서 얻은 교훈("빈도는 문제의 근거가 아니다")이 T12a에만 해당하는 줄 알았는데,
T12 전체에 해당했다.

### 11-3. 남은 항목

| 코드 | 근거 |
|---|---|
| **T1 줄표** | JH가 직접 지적했고("em-dash 좋게 생각 안 함") 정본 캘리브레이션이 있다 — JH 보이스 글은 0개 |
| **T2 종결 분포** | 최빈 종결 40% 초과. 실측 분포로 임계를 잡았다 |
| **T4 메타 예고문** | 실제 교정에서 23건을 고쳐 글이 나아지는 것을 확인했다 |
| **T7 고전 번역투** | 거의 0건이지만 재발 감시용으로 남긴다 |
| **V1·V2·V3** | 실제 교정에서 61건을 고쳐 확인했다 |
| T3·T5·T6·T8~T11 | 사람이 판단하는 항목. 기계 검출 없음 |
| T13 중의성 | 자리만. 기준 미확정 |

**교정으로 효과를 확인한 항목만 남았다.** T12는 고쳐 본 적이 없는 상태로 목록에 있었다.

### 11-4. 규칙 — 항목을 세우기 전에

1. 표본 **20건 이상**을 문맥과 함께 읽는다
2. 그중 **몇 건을 실제로 고쳐 보고**, 고친 글이 나아졌는지 확인한다
3. 그 뒤에 항목으로 세운다

빈도만 세고 항목을 만들면 **정상 한국어가 가장 많이 걸린다.** 자주 나오는 이유는
문제라서가 아니라 정상이라서다.
