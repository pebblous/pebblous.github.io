# 용어 대장

블로그에서 한 개념이 두 이름으로 갈릴 때, **무엇으로 정했고 왜 그렇게 정했는지**를 누적한다.
결정할 때마다 처음부터 다시 따지지 않기 위해서다.

## 0. 판정 기준 — 어원이 아니라 격 일치

**어느 쪽이 옳은 말이냐를 따지지 않는다.** 고유어라서 좋거나 한자어라서 나쁜 것이 아니다.
문제는 **한 글 안에서, 그리고 같은 자리에서 계열이 갈리는 것**이다.

실측이 이 기준을 뒷받침한다. '-값'과 '-치'는 **낱말마다 다른 쪽으로 굳었다.**

| 계열 | -값 | -치 | 어느 쪽으로 굳었나 |
|---|---:|---:|---|
| 이상값 / 이상치 | 6 | **201** | -치 |
| 임곗값 / 임계치 | 0 | **20** | -치 |
| 근삿값 / 근사치 | 0 | **7** | -치 |
| 측정값 / 측정치 | **35** | 9 | -값 |
| 최솟값 / 최소치 | **8** | 2 | -값 |
| 평균값 / 평균치 | **5** | 0 | -값 |
| 최댓값 / 최대치 | 6 | 7 | 갈림 |

어원으로는 설명되지 않는다. `이상치`는 한자어 쪽으로, `측정값`은 고유어 쪽으로 굳었고
둘 다 자연스럽다. **따라서 판정은 "이 낱말이 실제로 어느 쪽으로 굳었는가"와
"짝이 되는 낱말은 무엇을 쓰는가"로 한다.**

### 격의 단위 — 용어는 사이트, 문체는 문서

| 대상 | 단위 | 왜 |
|---|---|---|
| **용어** (개념의 이름) | **사이트 전체** | 한 개념이 두 이름으로 흩어지면 내부 링크와 검색 색인이 쪼개진다 |
| **문체** (종결·리듬·수식) | **문서 하나** | 글마다 톤이 다른 것은 정상이다 |

## 1. 확정

### 결측치 (← 결측값) · 2026-08-02

| | |
|---|---|
| **결정** | **결측치**로 통일한다 |
| 적용 | 사본 21편 39건 교정 완료 (PR #1133) |

**근거 넷.**

1. **빈도** — 결측치 54 : 결측값 34
2. **짝의 격** — 짝이 되는 `이상치`가 **201 : 6**으로 이미 굳어 있다
3. **갈림** — "이상치 탐지·**결측값** 처리"처럼 **한 문장에서 계열이 갈리는 곳이 12곳**이었다
4. **문맥** — 흔들리던 9편 중 7편에서 `이상값`은 0건이었다. 짝은 안 흔들리고 결측만 흔들렸다

> 이 항목이 격 일치 기준의 첫 적용 사례다. `결측값`이 틀린 말이라서 버린 것이 아니라,
> **같은 자리에 오는 `이상치`와 계열이 맞지 않아서** 버렸다. 교정 후 한 문장 갈림은 0곳이다.

## 2. 논쟁 중 — 결정하지 않았다

### 파인튜닝 / 미세조정

**원칙 둘이 정면으로 충돌한다.** 그래서 확정하지 않는다.

| 원칙 | 가리키는 답 | 근거 |
|---|---|---|
| **빈도 우선** | 파인튜닝 | **128 : 34.** 『2020 전문용어 표준화 안내서』도 "더 많이 사용되는 용어를 우선"한다 |
| **격 일치** | 미세조정 | 학습 계열이 **전부 한국어 번역어로 굳었다.** 그 속에서 fine-tuning만 음차다 |

격 일치 쪽 근거가 강하다. 학습 계열의 음차 표기는 **한 건도 없다.**

| 개념 | 우리가 쓰는 말 | 음차 표기 |
|---|---:|---:|
| pre-training | 사전학습 **125** | 프리트레이닝 **0** |
| reinforcement learning | 강화학습 **90** | 리인포스먼트 **0** |
| supervised learning | 지도학습 **29** | 슈퍼바이즈드 **0** |
| transfer learning | 전이학습 **6** | 트랜스퍼 러닝 **0** |
| distillation | 증류 **178** | 디스틸레이션 **0** |
| alignment | 정렬 **224** | 얼라인먼트 **0** |
| inference | 추론 **770** | 인퍼런스 **0** |
| **fine-tuning** | **미세조정 34** | **파인튜닝 128** ← 계열에서 홀로 튄다 |

**그런데 복합어에서는 이미 갈려 있다.** 실제 문장 하나가 그 증거다.

> "**파인튜닝**: 수집된 원시 출력으로 표준 지도 **미세조정**(SFT)을 수행한다"

`supervised fine-tuning(SFT)`은 "지도 미세조정"으로 옮기는 것이 관용이다. "지도 파인튜닝"은
쓰지 않는다. **단독으로 쓸 때와 복합어에 들어갈 때가 다르다.**

#### 검토할 만한 절충안

- 단독으로 쓸 때는 **파인튜닝** (빈도·업계 관용)
- 복합어에 들어갈 때는 **미세조정** (지도 미세조정 / SFT)
- 첫 등장에만 "파인튜닝(미세조정)"으로 병기

다만 이것은 **제안이지 결정이 아니다.** 혼용 글이 2편(`self-distillation-synthetic-data`,
`timesfm-industrial-forecasting`)뿐이라 급하지 않다. 판단이 설 때까지 대장에 남겨 둔다.

> ⚠️ **국립국어원 「다듬은 말」의 "정밀 조정"은 채택하지 않는다.** 『2020 전문용어 표준화
> 안내서』가 "특정 분야에서만 사용하며 국민 생활과 관련성이 낮은 경우"를 표준화 대상에서
> 제외하고 "더 많이 사용되는 용어를 우선시한다"고 명시한다. 우리 글에서 "정밀 조정"은 0건이다.

## 3. 흔들림 없음 — 손댈 것이 없다

실측해 보니 이미 한쪽으로 완전히 굳은 것들이다. 규칙으로 적어 둘 필요도 없지만,
**"흔들린다고 짐작해서 손대는 일"을 막으려고** 기록한다.

| 개념 | 우리가 쓰는 말 | 다른 후보 | 혼용 글 |
|---|---:|---:|---:|
| dataset | 데이터셋 **1,277** | 데이터 세트 0 | 0편 |
| agent | 에이전트 **2,794** | 대리자 0 | 0편 |
| embedding | 임베딩 **184** | — | 0편 |
| prompt | 프롬프트 **247** | 지시문 10 | 2편 |

`프롬프트/지시문`은 10건이 남아 있으나 대부분 일반 명사로서의 "지시문"이라 혼용이 아니다.

## 4. 기록 방법

새 항목을 올릴 때는 **반드시 실측을 먼저 낸다.** 짐작으로 낱말 표를 만들면 근거 없는 목록이
되고, 이후 모든 단계가 그것을 기계적으로 복제해 오히려 새 흔적을 만든다. 제목 규칙에서 이미
한 번 겪은 실패다.

각 항목에 적을 것:

1. **빈도** — 사이트 전체에서 각각 몇 건인가
2. **짝의 격** — 같은 자리에 오는 낱말은 어느 쪽으로 굳었는가
3. **갈림** — 한 문장·한 문서에서 계열이 갈리는 곳이 있는가 (있으면 그것이 결정적 근거다)
4. **결정과 날짜** — 확정 / 논쟁 중 / 흔들림 없음
5. **적용 범위** — 어느 PR에서 몇 건을 고쳤는가

원칙이 충돌하면 **억지로 확정하지 말고 "논쟁 중"에 둔다.** 판단을 유보했다는 것 자체가
정보다. 근거 없이 정해 놓으면 나중에 뒤집을 때 이미 수백 건이 그 규칙을 따른 뒤다.
