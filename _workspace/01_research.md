## 1차 출처 확인 결과 (Anthropic 공식 리서치 포스트, 2026-10-08)

출처: https://www.anthropic.com/research/the-missing-map-of-the-sky

### 배경 — 왜 자외선 지도에 빈 곳이 있었나
- 오존층이 자외선을 차단하기 때문에 우주에서만 관측 가능 — 지상 망원경으로는 원천적으로 불가
- NASA GALEX(2003~2013, 약 38,000회 관측)가 하늘의 약 2/3를 촬영했으나, 밝은 별 주변 손상 방지를 위해 일부 영역(별 형성 지역 등)을 의도적으로 회피
- 추가로 NASA Swift, 한국 과학기술위성 1호 탑재 FIMS/SPEAR, 유럽 TD-1이 보충 관측을 수행했지만 그래도 **전체 하늘의 약 1/3은 자외선 데이터가 전무**한 상태로 남음
- 존스홉킨스대 천체물리학자이자 Anthropic 연구원인 **브라이스 메나르(Brice Ménard)**가 "지루하고 까다로운 데이터 보정 작업에 수주 이상 걸리기 때문에 천문학자들이 전천 지도 완성을 후순위로 미뤄왔다"고 배경 설명

### 제작 방법 — Claude Science 에이전트 팀의 4단계
1. 공개 자외선 관측 데이터셋 수집(여러 미션 결과물 탐색·다운로드)
2. 각 데이터셋을 기기 간 비교 가능하도록 내부적으로 일관화(보정)
3. 서로 다른 망원경 데이터를 교차 검정해 하나의 좌표계로 통합, 밝은 별 주변 글레어 제거
4. **인페인팅(inpainting)** 머신러닝 기법으로 관측 자체가 없는 1/3 영역을 추정 — 가시광·적외선·전파 파장과 자외선 밝기 사이의 상관관계를 관측된 2/3 영역에서 통계적으로 학습한 뒤 미관측 영역에 적용(물리 기반 생성 모델링)

### 파장대 및 수치
- 원자외선(far-UV) **154nm** + 근자외선(near-UV) **232nm** 결합
- 가이아(Gaia) 가시광 관측으로부터 **1억 개 이상의 개별 별**의 자외선 밝기를 역산
- Planck, 수소-알파(H-alpha) 관측도 보조 자료로 활용

### 검증 — 홀드아웃(hold-out) 테스트
- 이미 자외선 데이터가 있는 영역 일부를 **의도적으로 가린 뒤** 모델이 그 값을 추정하도록 하고 실제값과 비교
- 결과: 추정값이 실제 측정치 대비 **평균 약 10% 이내** 오차
- ⚠️ **방법론적 한계(비판적 시각, runtimewire 기사에서 명시적으로 지적)**: "이 테스트는 선택된 '알려진' 영역에서의 성능을 보여줄 뿐, 실제 미관측 영역(은하면 등 더 복잡한 구조를 가진 1/3)에서도 동일한 정확도를 낸다는 것을 입증하지는 않는다" — 홀드아웃 성능과 실제 외삽 성능은 별개 질문이라는 지적. 이 지점이 "추정의 신뢰 구간을 어디까지 믿어야 하는가"라는 글의 앵글과 정확히 맞물림

### 불확실도 표시 — 픽셀 단위 라벨
- 최종 지도의 모든 픽셀에 **"측정됨(measured)" 또는 "예측됨(predicted)"** 라벨을 부여
- 예측 픽셀에는 별도의 **불확실도(uncertainty) 추정값**을 동반 제공 — 후속 연구자가 어느 값을 어느 정도 신뢰할지 스스로 판단할 수 있게 설계

### 사람이 잡아낸 오류 — 핵심 일화
- 메나르 교수가 지도의 어두운 영역에서 **희미한 원형 패턴(잔광 흔적)**을 육안으로 발견
- 이는 GALEX 개별 관측 장비 특유의 **지구 대기 자외선 잔류 발광(residual atmospheric glow)**이 제거되지 않고 남은 인공물(artifact)
- **에이전트 리뷰 2차례가 이 결함을 모두 놓쳤다** — 자동 검토 체계의 한계를 보여주는 대목
- 메나르가 지적하자 Claude Science는 **38,000건 전체 관측 데이터의 대기 잔광을 즉시 재수정**
- 외부 기술 분석가들의 평가: "AI 에이전트 교정 시스템이 도메인 지식을 갖춘 인간 전문가의 판단을 완전히 대체할 수 없음을 보여준 사례"

### 데이터 공개
- 지도는 연구 프로젝트 사이트 `menard.pha.jhu.edu/uvmap/`에서 전 세계 연구자에게 공개
- 원본 관측 데이터는 각 공개 아카이브(GALEX, Swift, FIMS/SPEAR, TD-1, Gaia)의 기존 공개 라이선스 하에 있음
- 용도: 명시적으로 **"신규 망원경 관측이나 실측 자외선 데이터의 대체물이 아닌, 교육·시각화 자원"**으로 포지셔닝 — 연구자가 결과를 인용할 때는 측정/예측 플래그를 반드시 구분해서 써야 함

### 작업 효율성 비교
- 사람이 수행했다면 수주(weeks)가 걸렸을 데이터 수집·보정·통합 작업을 Claude Science 에이전트가 며칠 안에 완료
- 메나르가 목표를 설정하고 산출물을 검수하는 "인간이 방향을 정하고 AI가 반복 작업을 수행"하는 역할 분담 구조

## 아웃라인

### 섹션 1: 인류가 한 번도 본 적 없는 하늘의 1/3
- 2026-10-08 발표 개요, GALEX가 왜 하늘의 2/3만 찍었는지, 왜 자외선은 우주에서만 관측 가능한지(오존층)

### 섹션 2: 빈 곳을 메우는 법 — 관측된 2/3에서 상관관계를 배운다
- 인페인팅 기법, 가시광·적외선·전파와 자외선의 상관관계 학습, 가이아 가시광 데이터로 별 1억 개 이상의 UV 밝기 역산, 154nm/232nm 결합

### 섹션 3: "10% 안쪽"이 증명하는 것과 증명하지 못하는 것
- 홀드아웃 테스트 설계, 평균 10% 오차의 의미, runtimewire가 짚은 한계(알려진 영역 성능 ≠ 미관측 영역 성능)

### 섹션 4: 진짜 성과는 추정이 아니라 "숨기지 않은 것"
- 픽셀마다 측정/예측 플래그 + 불확실도 동시 표기 설계, 이게 왜 추정 정확도 자체보다 중요한지(후속 연구자의 자기 판단권)

### 섹션 5: 에이전트 두 번이 놓친 걸 사람 눈이 잡았다
- 브라이스 메나르의 잔광 패턴 발견 일화, 38,000건 재수정, "AI 검토가 도메인 전문가를 대체하지 못한다"는 교훈

### 섹션 6: 당신이 받은 표에서 어느 칸이 관측이고 어느 칸이 모델값인가
- 페블러스 독자(데이터 실무자) 앵글로 전환 — AI가 채운 값이 섞인 데이터셋을 받을 때 이런 구분 라벨이 없다면 생기는 위험, 요구해야 할 최소 기준
