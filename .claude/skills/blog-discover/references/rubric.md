# 후보 채점 기준

각 항목 0~2점. **필수 항목이 0점이면 점수와 관계없이 탈락**. 합계로 칸 안 순위를 정한다.

| 항목 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 원 출처 (필수) | 논문 본문·공식 원문을 열어 수치까지 확인 | 원문은 확인, 핵심 수치는 2차 자료 | 2차 소개글뿐 |
| 증거 밀도 | 표·조건별 수치·실험 설계가 있다 | 수치 한두 개 | 주장뿐 |
| 핵심 검색어 | 사람들이 찾는 이름(모델·데이터셋·법·기관)이 있다 | 일반 주제어만 | 찾을 이름이 없다 |
| 페블러스 연결 (필수) | 소개 정본(정밀 겨냥 합성데이터 · 데이터클리닉 진단 · 데이터 그린하우스 · 데이터 품질 표준) 가운데 하나에 곧바로 닿는다 | 데이터·AI 일반으로 닿는다 | 연결을 지어내야 한다 |
| 축적성 (시리즈만) | 허브에 꽂혀 반년 뒤에도 찾아 읽을 글 | 한두 달 유효 | 소식이 지나면 끝 |
| 신선도 (소식만) | 사흘 안 | 2주 안 | 2주 넘음 |
| 독자 질문 | 실무자가 "그래서 우리 데이터는?"을 물을 수 있다 | 흥미는 있다 | 남의 일 |

- 데이터 의료 회사의 시선: 효과 없음·반증·재현 실패도 좋은 소재다. 음성 결과라고 깎지 않는다.
- 같은 점수면 우리가 아직 적게 쓴 하위 주제를 고른다(같은 연재의 최근 글과 겹치지 않게).
