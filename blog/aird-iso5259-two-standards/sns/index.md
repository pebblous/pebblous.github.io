AI 에이전트가 기업의 문서와 데이터를 찾아 쓰면서, 품질관리의 범위도 넓어지고 있다. 자료의 내용뿐 아니라 출처·기준 시점·사용 조건을 이해하고 따르는 능력이 필요하다.

AIRD는 이런 요구를 데이터 설명·품질 측정·목적별 준비 요건으로 구체화하는 움직임이다. 공개 리콜 사례에서는 품질 판정을 통과한 원천과, 목적 적합성 판정이 보류된 파생 RAG 팩을 구분했다. 원천 CSV 844행과 검색 조각 843개는 서로 다른 단위다.

페블러스는 이를 두 그린하우스의 협력 기회로 본다. Data Greenhouse는 여러 기준에 맞춰 데이터를 진단·개선하고, Agent Greenhouse는 그 자료를 쓰는 에이전트의 능력 부족을 개선해 시험·승인한 새 판본으로 돌려보내는 플랫폼을 지향한다. 고객이 자료와 기준을 바꿀 때 반복하는 검토·재작업·승인의 부담을 줄이는 것이 목표다.

공개 비교의 23/42→42/42는 7문항 반복이며, 정답 생성 규칙과 팩의 관계에 따른 한계도 함께 읽어야 한다.

## LinkedIn (EN)

As AI agents search enterprise information, data quality work reaches further into daily operations. Provenance, relevant dates and usage conditions become part of what agents need to interpret and apply.

AIRD is one initiative making these requirements explicit. Its public recall example separates a quality-assessed source from a derived RAG pack whose purpose-fitness verdict is on hold.

Pebblous sees an opportunity for two cooperating products: Data Greenhouse prepares and improves data against multiple requirements; Agent Greenhouse is being developed to improve capability gaps identified in agent work and return independently tested, approved versions to operations. The goal is to reduce repeated review, rework and approval effort as data and requirements change.

The published 23/42→42/42 comparison repeats seven questions and has an answer key tied to the pack-building rules. It is evidence within that test, not a general accuracy guarantee.
