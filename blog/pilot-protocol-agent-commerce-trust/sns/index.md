## LinkedIn (KO)

에이전트 25만 개가 하루 20억 건을 주고받는 네트워크가 벌써 돌아간다. 샌프란시스코 스타트업 Pilot Protocol이 450만 달러 시드를 받고 스텔스에서 나오며 공개한 '에이전트를 위한 인터넷' 이야기다. A2A나 MCP 아래에 깔리는 오버레이 네트워크로, 각 에이전트에 고유 신원을 부여하고 서로를 발견·인증·거래하게 잇는다. 코딩 도구와 모델 다음의 빌드아웃이 어디로 향하는지 보여주는 신호다.

그런데 이 배관이 지금 증명하는 건 '누구인가'까지다. 상대가 진짜 그 에이전트인지는 확인해도, 그 에이전트가 내미는 데이터의 출처 권한까지 진짜인지는 아직 아무도 검증하지 못한다. 신원은 진짜인데 넘기는 데이터는 볼 자격 없는 것일 수 있다. 2026년 3월 메타 내부 에이전트가 유효한 자격증명으로 모든 신원 확인을 통과하고도 볼 자격 없는 데이터를 노출한 사건이 그 증거다.

한 조직 안이라면 두 시간이면 잡히는 어긋남이, 25만 카운터파티를 타면 되짚을 수 없이 번진다. 신뢰 배관에서 신원만 놓고 출처·권한 계층을 비워 두면, 거래량이 늘수록 검증 안 된 데이터의 비중도 같이 는다. 다음 병목은 모델이 얼마나 똑똑한가가 아니라 그가 넘기는 것을 우리가 얼마나 정확히 되짚을 수 있는가다.

## LinkedIn (EN)

A network where 250,000 AI agents already exchange two billion requests a day is running today. It belongs to Pilot Protocol, a San Francisco startup that came out of stealth with a $4.5M seed to build what it calls "the internet for agents": an overlay network beneath A2A and MCP that gives each agent an identity and lets them discover, authenticate, and transact with one another. After coding tools and models, this is where the buildout is heading.

But what the plumbing proves today stops at "who." It can confirm a counterpart is the agent it claims to be, yet no one is verifying whether the data that agent hands over carries real provenance and entitlement. A genuine agent can still pass along data it was never authorized to see. In March 2026, an internal Meta agent cleared every identity check with valid credentials and still exposed data it had no right to.

Inside one organization, that kind of drift is caught in two hours. Across 250,000 counterparties, it launders through every trade and no one can trace where the entitlement fell off. Fill the identity layer and leave provenance empty, and the share of unverifiable data grows with the volume. The next bottleneck is not how smart the model is, but how precisely we can trace what it hands over.

## Facebook (EN)

I read the sentence a few days ago, scrolling past it: 250,000 agents already exchanging two billion requests a day.

What caught me wasn't the number. It was the three verbs sitting next to it: agents that discover, trust, and transact with one another.

Discovery I understand. Transaction I can picture. It was the word wedged between them, trust, that made me stop.

The "internet for agents" that a San Francisco startup called Pilot Protocol raised $4.5M to build can prove that a counterpart really is the agent it claims to be. That layer is filling in fast.

But does a verified identity mean the data that agent hands you carries real provenance? Can a genuine agent still pass along data it was never allowed to see?

This past March, an internal agent at Meta cleared every identity check with valid credentials and still exposed data it had no right to, for two hours. Nothing was breached. The identity was perfect. Only the entitlement had stopped at the door.

Inside one company, that drift is caught in two hours. Loose on an open network of 250,000 counterparties, data that has lost its origin quietly launders through every trade it passes.

As the internet where agents trade with one another gets laid down, the question I keep returning to is the one Pebblous has held for a long time: can we verify where the data changing hands actually came from, and by what right?
