## LinkedIn · Facebook (KO)

금융위원회가 11월 27일부터 개인사업자의 기본·재무·금융정보를 지어낸 숫자로 공공데이터포털에 연다.

11월 26일 보도자료에 따르면 추가 개방되는 금융공공데이터 API 여섯 개 가운데 셋이 개인사업자 합성데이터다. 신용보증기금·산업은행·기업은행·주택금융공사·서민금융진흥원이 거래 기록을 댔고, 원본 줄 대신 분포와 항목 사이의 관계만 물려받은 줄을 새로 썼다. 같은 다섯 기관의 같은 데이터는 2022년 11월에 단순 가명처리로 열렸다. 그때 열린 네 개가 그대로 남아 개인사업자정보 API는 일곱 개가 된다.

합성이 적절한지는 금융보안원이 평가했다고 보도자료가 밝혔지만, 무엇을 어떤 기준으로 봤는지는 공개 자료에서 확인되지 않는다. 금융위원회는 1년 전 보도자료에서 그 활용기준을 2026년 1분기까지 내놓겠다고 적었다.

전문은 이 개방을 공공데이터의 기본값이 가리기에서 다시 짓기로 옮겨 간 자리로 짚었다. 합성데이터 평가는 보통 재식별 위험을 보는 안전성과 원본 대신 써도 같은 결론에 닿는지 보는 유용성, 두 축으로 갈린다. 이 데이터로 소상공인 신용평가 모형을 만들려는 팀이 먼저 물을 것은 받은 합성본이 어느 쪽 보증을 받았는가다.

## LinkedIn · Facebook (EN)

From November 27 Korea's Financial Services Commission publishes sole proprietor profile, financial statement and banking records that were invented, not collected.

The announcement, dated November 26, adds six financial public data APIs to the portal; three hold synthetic sole proprietor data. Five state financial institutions, among them Korea Credit Guarantee Fund, supplied the transaction records behind them, and what goes out is rows written from scratch to match only the original's distributions and correlations. The same data from the same institutions was opened once before, in 2022, by pseudonymization. Those four APIs stay in place, so the field now holds seven.

The Financial Security Institute assessed whether the synthesis was adequate, the release says, but what it examined and against which standard appears nowhere in public material. A year ago the Commission promised such a standard by the first quarter of 2026.

The full analysis reads this as the default for open government data shifting from masking to rebuilding. Assessments of synthetic data split into safety, which asks about re-identification, and utility, which asks whether a conclusion survives the swap. Anyone training a small business credit model here should ask which guarantee the data carries.
