# 엔비디아 Cosmos Data Factory, 

_엔비디아는 합성 자율주행 영상이 도로 촬영보다 45배 싸다고 했지만, 스스로 밝힌 서버 비용으로 나누면 17배 남짓_

## Executive Summary

> [!callout]
> 엔비디아가 로봇과 자율주행차를 가르칠 합성데이터를 만드는 도구 묶음 Cosmos Data Factory를 내놓고, 자율주행 장면 데이터를 도로에서 찍어 모으는 것보다 약 45배 싸게 만든다고 밝혔다. 11월 18일 엔비디아 개발자 블로그에 실린 발표에 따르면 묶음은 완성된 작업 단위인 블루프린트 5종과 공용 부품인 스킬 6종으로 짜여 있고, 데이터셋을 꾸리는 시간은 최대 60배 줄어든다.

> 45배는 합성 클립 하나에 드는 GPU 연산비 2.66달러를 도로 수집 125달러와 견준 값이다. 그런데 발표가 직접 적은 계산법은 하루 서버 비용 960달러를 하루 산출량으로 나누는 것이고, 자율주행 블루프린트의 하루 산출량 130클립으로 나누면 클립당 7.38달러가 된다. 이 값으로 다시 견주면 17배 남짓이다. 같은 발표의 다른 블루프린트 셋은 이 계산법으로 960달러가 맞아떨어지고, 자율주행만 맞지 않는다. 엔비디아는 이 수치가 연산비만 담았고 데이터 준비와 사람 검수 비용은 빠졌다고 스스로 적었다.

> 성능 근거로 실린 것은 산업 점검 로봇 회사 ANYbotics 사례 하나다. 원 출처인 Encord 글을 보면 '재현율 최대 24% 개선'은 물체가 새로 나타난 장면의 수치이고, 함께 묶인 '투자 대비 1,400배'는 재현율이 8% 오른 액체 유출 장면에서 나온 값이다. 이 사례는 이상 탐지 모델의 판정 경계를 합성 클립으로 보정한 것이었고, 정상 장면 오경보도 함께 늘었다. 합성데이터로 학습한 모델과 실데이터로 학습한 모델을 견준 결과는 발표 어디에도 없다. 1~5절은 확인한 사실과 회사들의 주장이고, 6절은 페블러스의 해석이다.

### 주요 수치

아래 네 수치 가운데 앞의 둘은 가격표, 뒤의 둘은 성능 근거에 관한 것이다. 가격표 쪽은 발표값과 발표 계산법을 그대로 따른 값을 나란히 적었고, 성능 쪽은 Encord 원문의 이상 유형별 수치와 발표에 없는 비교를 적었다.

## 엔비디아 Cosmos Data Factory, 블루프린트 5종·스킬 6종 공개

엔비디아는 2026년 11월 18일 개발자 블로그에 「Build Training-Ready Physical AI Datasets with Two Prompts in NVIDIA Cosmos」라는 글을 올렸다. 글쓴이는 엔비디아 Metropolis 제품관리 디렉터 나쿨 아로라(Nakul Arora)다. 제목대로 프롬프트 두 번이면 물리 AI 학습용 데이터셋을 만들 수 있다는 것이 발표의 요지다. 물리 AI는 로봇, 자율주행차, 공장 검사 카메라처럼 실제 공간에서 움직이고 판단하는 AI를 가리킨다.

Cosmos Data Factory는 두 층으로 짜여 있다. 아래층의 스킬 6종은 자동 라벨링(Auto Labeling), 이상 장면 생성(AnomalyGen), 증강(Augmentation), 선별·검색(Curation and Retrieval), 시뮬레이션(Simulation), 작업 조율(Orchestration)이다. 위층의 블루프린트 5종은 이 스킬을 엮어 한 가지 일을 끝까지 해내는 작업 단위로, 자율주행 데이터셋 생성, 이미지 속성 증강, 비디오 데이터 증강, 이벤트 영상 생성, 결함 이미지 생성이다. 블루프린트 다섯 모두 작업 조율 스킬 위에서 돈다.

코드는 GitHub 저장소 NVIDIA/cosmos-data-factory에 공개됐다. 코드는 Apache-2.0, 문서와 스킬 내용은 CC-BY-4.0 라이선스이고, 저장소는 지금 외부 기여를 받지 않는다고 밝혀 두었다. 저장소에는 블루프린트마다 필요한 GPU 수가 적혀 있는데, 자율주행 블루프린트는 로컬 모델 기준 4장이고 외부 모델 서버 연결은 지원하지 않는다. 결함 이미지 생성 블루프린트는 PCB, 금속, 유리 부품 이미지를 기준으로 만들어졌다. 생성된 영상의 물리적 정확성, 사물 일관성, 환각 여부를 검사하는 Cosmos Evaluator가 기본으로 함께 돈다.

발표는 블루프린트마다 하루 산출량과 단가를 따로 적었다. 엔비디아가 밝힌 수치를 옮기면 다음과 같다.

표의 비교 대상 칸은 줄마다 다르다. 자율주행은 도로 수집팀의 비용과, 두 증강 블루프린트는 외부에서 사는 데이터의 평균값과 견줬고, 결함 이미지는 돈이 아니라 걸린 시간과 견줬다. 이벤트 영상 생성은 단가만 있고 견줄 대상이 없다. 배수 칸의 숫자들은 서로 다른 기준에서 나왔으니, 한 줄로 세워 크기를 비교할 수 없다.

| 블루프린트 | 하루 산출량 | 단가 | 비교 대상 | 배수 |
| --- | --- | --- | --- | --- |
| 자율주행 데이터셋 생성 | 약 130클립 | 클립당 $2.66(GPU 연산) | 도로 수집팀 시나리오당 $125 | 약 45배 |
| 이미지 속성 증강 | 약 42,649쌍 | 쌍당 $0.023 | 외부 구매 데이터 평균 $0.25 | 약 10배 |
| 비디오 데이터 증강 | 약 305클립 | 약 5분 클립당 $3.15 | 외부 구매 평균 $22 | 약 7배 |
| 이벤트 영상 생성 | 약 384클립 | 클립당 $2.50 | 제시 없음 | 제시 없음 |
| 결함 이미지 생성 | 제시 없음 | 제시 없음 | 데이터셋 조립 2개월 → 1일 | 60배(시간) |

▲ 엔비디아 발표의 블루프린트별 수치. 측정 환경은 RTX PRO 6000 Blackwell GPU 8장을 단 클라우드 서버 1대, 서버 시간당 약 40달러(하루 960달러). 출처: [엔비디아 개발자 블로그](https://developer.nvidia.com/blog/build-training-ready-physical-ai-datasets-with-two-prompts-in-nvidia-cosmos/)

고객 사례도 넷 실렸다. 지멘스는 자동 광학 검사 프로그램을 만드는 수작업을 최대 85% 줄이고 오판정을 40% 줄이는 것을 목표로 한다. 폭스바겐은 반복 실차 주행 시험을 최대 90%, AI 회귀 시험 주기를 최대 85% 줄일 것으로 예상한다. Centific은 자체 구축에 6개월이 걸렸을 일을 Cosmos Curator로 2주 안에 출시했다고 한다. 지멘스와 폭스바겐 수치에는 '목표'와 '예상'이라는 말이 붙어 있어 이미 측정한 결과로 읽을 수 없다. 측정 결과로 실린 것은 네 번째인 ANYbotics 사례뿐이고, 4절에서 따로 다룬다.

## Cosmos Data Factory의 '60배'는 결함 이미지, '45배'는 자율주행

엔비디아 발표의 머리 문장은 "최대 60배 빠른 데이터셋 조립과 45배 싼 자율주행 시나리오 생성"이다. 두 숫자는 서로 다른 블루프린트에서 나왔다. 60배는 결함 이미지 생성 블루프린트가 데이터셋 조립 기간을 2개월에서 하루로 줄였다는 사례이고, 45배는 자율주행 데이터셋 생성 블루프린트의 클립 단가에서 나왔다.

나머지 블루프린트의 배수는 이보다 훨씬 작다. 이미지 속성 증강은 약 10배, 비디오 데이터 증강은 약 7배이고, 이벤트 영상 생성은 견줄 대상을 내놓지 않았다. 60배를 낸 결함 이미지 생성 블루프린트는 반대로 하루 산출량도 단가도 공개하지 않았다. 다섯 블루프린트 가운데 가장 큰 두 숫자를 하나씩 골라 한 문장에 넣은 것이 머리 문장이다.

45배의 두 항도 같은 단위인지 발표만으로는 알 수 없다. 합성 쪽은 클립 하나의 연산비이고, 도로 쪽은 수집팀이 시나리오 하나를 모으는 비용이다. 도로에서 시나리오 하나를 찍으면 학습용 클립이 몇 개 나오는지, 합성 클립 하나가 도로 시나리오 하나의 몫을 하는지는 적혀 있지 않다. 125달러가 어떤 조건의 수집팀 비용인지도 밝히지 않았다.

## 엔비디아 클립당 2.66달러, 자기 계산법으로는 7.38달러

엔비디아는 단가를 어떻게 냈는지 한 문장으로 밝혔다. RTX PRO 6000 Blackwell GPU 8장을 단 클라우드 서버에서 하루 산출량을 측정했고, 서버값을 시간당 약 40달러, 하루 960달러로 잡아 하루 비용을 산출량으로 나눠 자산당 비용을 추정했다는 것이다.

이 계산법을 블루프린트마다 거꾸로 적용해 보면 결과가 갈린다. 하루 산출량에 단가를 곱하면 하루 비용이 나와야 한다. 이미지 속성 증강은 42,649쌍에 0.023달러를 곱해 약 981달러, 비디오 데이터 증강은 305클립에 3.15달러를 곱해 약 961달러, 이벤트 영상 생성은 384클립에 2.50달러를 곱해 960달러다. 셋 다 서버 하루 비용과 맞는다. 이미지 속성 증강은 발표 문장 안에 "하루 960달러"가 직접 적혀 있기도 하다.

자율주행 블루프린트만 맞지 않는다. 130클립에 2.66달러를 곱하면 약 346달러로, 서버 하루 비용 960달러의 3분의 1을 조금 넘는다. 아래 그림은 네 블루프린트의 하루 비용을 발표 수치로 다시 계산한 결과다.
