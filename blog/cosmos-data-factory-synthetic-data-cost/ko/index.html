Executive Summary

엔비디아가 2026년 11월 18일 개발자 블로그에서 피지컬 AI 학습 데이터 생성 도구 묶음 Cosmos Data Factory를 공개했다. 프롬프트 두 번이면 로봇과 자율주행차를 가르칠 학습용 데이터셋을 만들 수 있다는 것이 발표의 요지다. 묶음은 완성된 작업 단위인 블루프린트 5종과 공용 부품인 스킬 6종으로 짜여 있다. 코드는 GitHub 저장소 NVIDIA/cosmos-data-factory에 Apache-2.0 라이선스로 공개됐다.

엔비디아는 블루프린트마다 하루 산출량과 단가를 밝혔다. GPU 8장을 단 클라우드 서버 1대 기준으로 이미지 속성 증강은 하루 약 42,649쌍을 쌍당 0.023달러에, 비디오 데이터 증강은 약 305클립을 클립당 3.15달러에, 이벤트 영상 생성은 약 384클립을 클립당 2.50달러에 만든다. 자율주행 데이터셋 생성은 하루 약 130클립을 만들고, 엔비디아는 클립당 연산비 2.66달러가 도로 수집 125달러보다 약 45배 저렴하다고 밝혔다. 결함 이미지 생성은 데이터셋 조립 기간을 2개월에서 하루로 줄여 최대 60배 빨라졌다.

고객 사례도 넷 실렸다. 지멘스는 자동 광학 검사 프로그램을 만드는 수작업을 최대 85% 줄이는 것을 목표로 하고, 폭스바겐은 반복 실차 주행 시험을 최대 90% 줄일 것으로 예상한다. Centific은 자체 구축에 6개월이 걸렸을 일을 Cosmos Curator로 2주 안에 출시했다고 밝혔다. Encord가 공개한 ANYbotics 사례에서는 합성 이상 장면으로 점검 로봇의 변화 감지 모델을 보정해 실제 이상의 재현율이 최대 24% 올랐다.

엔비디아는 단가가 연산비만 담았다고 밝혔다. 공개된 하루 서버 비용 960달러를 하루 약 130클립으로 나눈 자율주행 클립당 연산비는 7.38달러이고, 발표된 2.66달러와의 차이는 발표 자료만으로 설명할 수 없다(3절). 발표에는 합성데이터 학습 모델과 실데이터 학습 모델을 견준 결과가 없다. 1~5절은 확인한 사실과 회사들의 주장이고, 6절은 페블러스의 해석이다.

1

엔비디아 Cosmos Data Factory, 블루프린트 5종·스킬 6종 공개

엔비디아는 2026년 11월 18일 개발자 블로그에 「Build Training-Ready Physical AI Datasets with Two Prompts in NVIDIA Cosmos」라는 글을 올렸다. 글쓴이는 엔비디아 Metropolis 제품관리 디렉터 나쿨 아로라(Nakul Arora)다. 제목대로 프롬프트 두 번이면 피지컬 AI 학습용 데이터셋을 만들 수 있다는 것이 발표의 요지다. 피지컬 AI(물리 AI)는 로봇, 자율주행차, 공장 검사 카메라처럼 실제 공간에서 움직이고 판단하는 AI를 가리킨다.

Cosmos Data Factory는 두 층으로 짜여 있다. 아래층의 스킬 6종은 자동 라벨링(Auto Labeling), 이상 장면 생성(AnomalyGen), 증강(Augmentation), 선별·검색(Curation and Retrieval), 시뮬레이션(Simulation), 작업 조율(Orchestration)이다. 위층의 블루프린트 5종은 이 스킬을 엮어 한 가지 일을 끝까지 해내는 작업 단위로, 자율주행 데이터셋 생성, 이미지 속성 증강, 비디오 데이터 증강, 이벤트 영상 생성, 결함 이미지 생성이다. 블루프린트 다섯 모두 작업 조율 스킬 위에서 돈다.

코드는 GitHub 저장소 NVIDIA/cosmos-data-factory에 공개됐다. 코드는 Apache-2.0, 문서와 스킬 내용은 CC-BY-4.0 라이선스이고, 저장소는 지금 외부 기여를 받지 않는다고 밝혀 두었다. 저장소에는 블루프린트마다 필요한 GPU 수가 적혀 있는데, 자율주행 블루프린트는 로컬 모델 기준 4장이고 외부 모델 서버 연결은 지원하지 않는다. 결함 이미지 생성 블루프린트는 PCB, 금속, 유리 부품 이미지를 기준으로 만들어졌다. 생성된 영상의 물리적 정확성, 사물 일관성, 환각 여부를 검사하는 Cosmos Evaluator가 기본으로 함께 돈다.

발표는 블루프린트마다 하루 산출량과 단가를 따로 적었다. 엔비디아가 밝힌 수치를 옮기면 다음과 같다.

표의 비교 대상 칸은 줄마다 다르다. 자율주행은 도로 수집팀의 비용과, 두 증강 블루프린트는 외부에서 사는 데이터의 평균값과 견줬고, 결함 이미지는 걸린 시간과 견줬다. 이벤트 영상 생성은 단가만 있고 견줄 대상이 없다. 배수 칸의 숫자들은 서로 다른 기준에서 나왔으니, 한 줄로 세워 크기를 비교할 수 없다.

고객 사례도 넷 실렸다. 지멘스는 자동 광학 검사 프로그램을 만드는 수작업을 최대 85% 줄이고 오판정을 40% 줄이는 것을 목표로 한다. 폭스바겐은 반복 실차 주행 시험을 최대 90%, AI 회귀 시험 주기를 최대 85% 줄일 것으로 예상한다. Centific은 자체 구축에 6개월이 걸렸을 일을 Cosmos Curator로 2주 안에 출시했다고 한다. 지멘스와 폭스바겐 수치는 '목표'와 '예상'으로 제시됐다. 네 번째인 ANYbotics 사례는 측정 결과로 실렸고, 4절에서 따로 다룬다.

2

Cosmos Data Factory의 '60배'는 결함 이미지, '45배'는 자율주행 블루프린트

엔비디아 발표의 머리 문장은 "최대 60배 빠른 데이터셋 조립과 45배 싼 자율주행 시나리오 생성"이다. 두 숫자는 서로 다른 블루프린트에서 나왔다. 60배는 결함 이미지 생성 블루프린트가 데이터셋 조립 기간을 2개월에서 하루로 줄였다는 사례이고, 45배는 자율주행 데이터셋 생성 블루프린트의 클립 단가에서 나왔다.

발표는 두 증강 블루프린트의 단가를 외부 구매 데이터 평균과 견줬다. 이미지 속성 증강은 약 10배, 비디오 데이터 증강은 약 7배 저렴하다. 이벤트 영상 생성은 단가만 밝혔고, 결함 이미지 생성은 하루 산출량과 단가를 공개하지 않았다.

45배의 두 항은 단위가 다르다. 합성 쪽은 클립 하나의 연산비이고, 도로 쪽은 수집팀이 시나리오 한 건을 모으는 비용이다. 도로 시나리오 한 건에서 학습용 클립이 몇 개 나오는지, 125달러가 어떤 조건의 수집팀 비용인지는 발표에 적혀 있지 않다.

3

자율주행 블루프린트 단가, 공개 계산법으로 다시 나눈 값

엔비디아는 단가를 어떻게 냈는지 한 문장으로 밝혔다. RTX PRO 6000 Blackwell GPU 8장을 단 클라우드 서버에서 하루 산출량을 측정했고, 서버값을 시간당 약 40달러, 하루 960달러로 잡아 하루 비용을 산출량으로 나눠 자산당 비용을 추정했다는 것이다.

이 계산법대로라면 하루 산출량에 단가를 곱한 값이 하루 서버 비용이 된다. 이미지 속성 증강은 42,649쌍에 0.023달러를 곱해 약 981달러, 비디오 데이터 증강은 305클립에 3.15달러를 곱해 약 961달러, 이벤트 영상 생성은 384클립에 2.50달러를 곱해 960달러다. 셋 다 서버 하루 비용 960달러와 맞는다. 이미지 속성 증강은 발표 문장 안에 "하루 960달러"가 직접 적혀 있기도 하다.

자율주행 블루프린트는 130클립에 2.66달러를 곱하면 약 346달러다. 서버 하루 비용 960달러의 3분의 1을 조금 넘는 값이다. 아래 그림은 네 블루프린트의 하루 비용을 발표 수치로 다시 계산한 결과다.

2.66달러는 엔비디아가 발표한 자율주행 합성 클립당 GPU 연산비다. 공개된 하루 서버 비용 960달러를 하루 약 130클립으로 나누면 7.38달러가 된다. 이 값은 공개 수치로 검산한 연산비이며, 실측 단가나 총원가가 아니다. 두 금액의 차이는 발표 자료만으로 설명할 수 없다. GitHub 저장소는 자율주행 블루프린트에 GPU 4장이 든다고 적었고, 서버의 절반인 하루 480달러로 나누면 클립당 약 3.69달러다. 346달러는 서버를 하루 약 8.6시간 돌린 비용에 해당한다.

125달러는 도로에서 시나리오 한 건을 수집하는 비용이고, 2.66달러와 7.38달러는 클립당 연산비다. 125달러를 7.38달러로 나누면 약 17배가 된다. 이 값은 공개값을 단순히 나눈 결과이며, 실제 절감률을 나타내지 않는다.

단가에 무엇이 빠졌는지는 엔비디아가 직접 적었다. 발표에는 다음 문장이 있다.

Note that these figures cover compute only; source data preparation, setup, agent use, storage, and human review may add costs.

이 수치는 연산비만 담았다. 원본 데이터 준비, 설정, 에이전트 사용, 저장, 사람 검수에 비용이 더 들 수 있다.

실제로 쓸 수 있는 클립 한 편의 원가는 같은 배치의 GPU 연산비에 별도로 발생한 원본 준비·환경 설정·에이전트 사용·검수·저장 비용을 더해 최종 채택 편수로 나눈 값이다. GPU 연산비에 이미 들어간 검사·재생성 비용은 중복 합산하지 않는다.

하루 130편이 검수 전 생성량인지 최종 통과량인지는 공개 설명만으로 명확하지 않다. 별도 비용과 최종 채택 편수를 모르니 총원가나 수율은 추정하지 않는다.

4

ANYbotics 점검 로봇, 합성 이상 장면으로 재현율 최대 24% 개선

엔비디아 발표에 성능 사례로 실린 것은 "Encord를 통한 ANYbotics" 사례다. 이 사례는 데이터 플랫폼 회사 Encord가 2026년 10월 21일 자사 연구 조직 Encord Data Labs 이름으로 낸 글에서 나왔다. Encord 글은 이벤트 영상 생성 기능이 GTC Berlin 2026에서 정식 공개되기 전에 ANYbotics 산업 현장 이미지에 먼저 적용해 본 결과라고 밝혔다. 평가 날짜는 그림 설명에 2026년 9월 25일로 적혀 있다.

4.1ANYbotics가 합성 클립을 쓴 자리

ANYbotics의 네 발 점검 로봇 ANYmal은 석유·가스 시설, 발전소, 공장처럼 사람이 정기 순찰을 돌기 위험하거나 먼 곳에 배치된다. 로봇은 순찰마다 같은 점검 지점으로 돌아가 사진을 찍고, 변화 감지 모델이 그 사진을 해당 지점의 평소 사진 분포와 비교해 벗어나면 이상으로 표시한다. Encord 글에 따르면 잘 관리되는 현장은 이상이 거의 없어 로봇이 몇 달을 순찰해도 하나도 못 만날 수 있고, 그래서 어디서부터 이상으로 볼지 경계를 실제 이상 사례 없이 정하는 일이 잦다.

Encord 팀은 참조 이미지 410장에서 아홉 가지 변화 유형에 걸쳐 클립 1,500개 이상을 만들었다. ANYbotics는 클립마다 여러 프레임을 뽑아, 이미 쓰던 변화 감지 모델의 판정 경계를 보정하는 데 썼다. 기존 모델의 기준선을 합성 이상 장면으로 조정하는 방식이다.

4.2재현율 표

평가는 평소 사진만으로 정한 경계와 평소 사진에 합성 프레임을 더해 정한 경계를, 같은 점검 지점의 실제 이상 사례로 채점해 비교했다. 실제 이상을 얼마나 놓치지 않고 잡았는지를 보는 재현율이 지표다.

액체 유출 9곳 0.47 0.50 +8%
전체 25곳 0.50 0.62 +24%

▲ 실제 이상 사례에 대한 평균 재현율. 상대 변화는 Encord 그림 2의 표기. ANYbotics 평가, 2026년 9월 25일. 출처: Encord Data Labs

24%는 상대 변화다. 물체 출현의 재현율은 0.54에서 0.67로 13%포인트 올랐고, 전체는 0.50에서 0.62로 12%포인트 올랐다. 액체 유출은 0.47에서 0.50으로 3%포인트 올랐다. 채점에 쓴 점검 지점은 전체 25곳이고 액체 유출은 9곳이다.

Encord 글 머리의 요약은 액체 유출 탐지가 10% 좋아졌다고 적었다. 이 10%는 탐지 정확도(detection accuracy) 기준이다. 본문은 물체 출현과 액체 유출 모두 탐지 정확도가 10% 올랐고, 재현율은 각각 24%와 8% 올랐다고 쓴다. 보정에 쓴 예시 수도 공개됐다. 물체 출현은 실제 이상 237건에 합성 525건이 더해져 221%가 늘었고, 액체 유출은 실제 205건에 합성 92건이 더해져 45%가 늘었다.

4.3ANYbotics가 함께 밝힌 한계

Encord 글은 부작용도 적었다. 합성 이상 장면으로 보정하자 정상 장면에서 울리는 오경보 비율도 올라갔고, 일부 변화 유형은 의미 있게 나아지지 않았다. Encord 팀은 조명, 각도, 흐림을 바꾼 평소 사진 증강을 함께 쓰면 이 간극을 줄일 수 있을 것이라는 가설을 내놨지만, 검증 결과는 싣지 않았다.

ANYbotics의 평가는 다음과 같이 옮겨져 있다.

ANYbotics assessed that real anomalies remain stronger calibration data where they exist, but since they are sparse and unknown in advance, synthetic data gives a meaningful head start on change types with few or no real examples.

ANYbotics는 실제 이상 사례가 있는 곳에서는 여전히 그쪽이 더 강한 보정 데이터라고 평가했다. 다만 실제 사례는 드물고 미리 알 수 없어서, 실제 예시가 거의 없거나 전혀 없는 변화 유형에서는 합성데이터가 의미 있는 출발점이 된다고 봤다.

5

ANYbotics 사례의 '24%'와 '1,400배', Encord 원문의 이상 유형별 수치

엔비디아 발표는 ANYbotics 사례를 "합성데이터로 실제 이상의 재현율을 최대 24% 높였고, 해상 석유·가스 시설에서 데이터 생성비 대비 1,400배의 수익이 추정된다"고 소개했다. Encord 원문에서 두 숫자는 서로 다른 변화 유형에서 나왔다.

Encord가 수익을 계산한 것은 액체 유출뿐이다. 액체 유출 재현율을 8% 높인 합성 클립은 만드는 데 55달러, 클립당 약 60센트가 들었다. ANYbotics는 액체 유출을 8% 더 잡는 가치를 현장 유형별로 매겼다. 화학 공장은 연 22,800달러로 생성비의 415배, 수력 발전소는 연 31,400달러로 571배, 해상 석유·가스 시설은 연 78,500달러로 1,427배다. 장비 손상, 가동 중단, 안전사고, 환경 벌금을 피한 값을 스위스 프랑에서 달러로 바꾼 ANYbotics의 추정치다. 재현율이 24% 오른 물체 출현에 대해서는 생성비도 가치도 공개되지 않았다.

Encord는 글 머리에서 화학 공장 수치를 들어 "현장당 연 22,000달러 이상, 생성비의 400배 이상"이라고 썼다. 엔비디아 발표의 1,400배는 해상 석유·가스 시설의 1,427배에 해당한다.

비용의 기준도 엔비디아 발표와 다르다. Encord는 55달러가 연산비에 설정 비용의 할당분을 더한 값이라고 그림 설명에 밝혔다. 엔비디아의 블루프린트 단가는 연산비만 담았다. 같은 이벤트 영상 생성 기능인데 Encord 사례는 클립당 약 60센트, 엔비디아 발표는 클립당 2.50달러로 적혀 있다. 클립 길이와 산정 범위가 공개돼 있지 않아 두 단가를 나란히 놓고 견줄 수는 없다.

ANYbotics 평가는 9월 25일, Encord 공개는 10월 21일, 엔비디아 발표는 11월 18일이다.

5.1확인한 것, 회사들이 주장한 것, 페블러스의 해석

세 갈래는 근거의 무게가 다르다. 앞의 둘은 1차 출처를 짚을 수 있고, 마지막은 페블러스의 판단이다.

갈래 내용
1차 자료로 확인 블루프린트 5종과 스킬 6종의 이름, 블루프린트별 하루 산출량과 단가, 측정 서버 조건(GPU 8장, 시간당 약 40달러), 연산비만 담았다는 단서 문장. 저장소의 라이선스와 블루프린트별 GPU 수. Encord 원문의 재현율 표, 액체 유출 생성비 55달러와 현장별 가치 추정, 오경보 증가, ANYbotics의 평가 문장. 이미지 속성 증강·비디오 데이터 증강·이벤트 영상 생성의 하루 비용이 960달러이고 자율주행이 346달러라는 점은 발표 수치로 다시 계산할 수 있다
회사들의 주장 엔비디아의 '최대 60배 빠르고 45배 싸다', 지멘스와 폭스바겐의 목표·예상 수치, Centific의 2주 출시. 1,400배 수익은 ANYbotics의 추정이다. 독립 제3자의 재현 결과는 아직 공개되지 않았다
페블러스의 해석 Cosmos Data Factory 발표는 블루프린트별 하루 산출량, 단가, 측정 서버 조건을 함께 공개해 도입 팀이 자기 조건으로 비용을 다시 계산할 수 있게 했다. 자율주행 단가 2.66달러와 공개 계산법으로 나눈 7.38달러의 차이는 발표 자료만으로 설명할 수 없다. ANYbotics 사례는 실제 이상 사례로 채점하고 오경보 증가까지 함께 적어, 발표 안에서 가장 구체적인 성능 근거다
6

페블러스가 이 소식을 주목하는 이유

Cosmos Data Factory 발표로 합성데이터에 블루프린트별 하루 산출량과 클립당 가격이 붙었다. 산출량과 서버 조건이 함께 공개돼, 도입 팀은 자기 서버로 비용을 미리 계산해 볼 수 있다. 엔비디아는 생성 영상의 물리적 정확성, 사물 일관성, 환각 여부를 검사하는 Cosmos Evaluator를 기본으로 붙였다. 도입 팀이 여기에 더해 확인할 것은 생성한 클립이 자기 모델에 모자란 장면을 채우는지다.

ANYbotics 사례는 그 확인을 어떻게 하는지 보여 준다. 합성 클립을 넣기 전과 후를 같은 점검 지점의 실제 이상 사례로 채점했고, 오경보 변화도 함께 적었다. 개선 폭은 변화 유형마다 달랐다. 정밀하게 겨냥한 합성데이터의 효과는 이런 실측으로 확인된다.

Cosmos Data Factory 같은 합성데이터 생성 도구를 들인 팀이 결과물을 점검하는 방법은 셋이다.

  • • 단가를 자기 서버 조건으로 다시 계산한다. 하루 산출량과 서버 비용이 함께 공개돼 있어 곱해 보면 된다. 자율주행 블루프린트는 3절처럼 발표 단가와 검산값을 나란히 놓고 본다
  • • 최종 채택 편수로 원가를 잡는다. 같은 배치의 GPU 연산비에 원본 준비·환경 설정·에이전트 사용·검수·저장 비용을 더하고, 검수를 통과해 실제로 쓰는 클립 수로 나눈다
  • • 실제 데이터로 채점한다. 합성 클립을 넣은 모델을 실제 사례로 다시 측정하고, 오경보처럼 나빠질 수 있는 지표도 함께 본다

Editor's Note

7.38달러는 엔비디아 발표에 적힌 서버 비용과 하루 산출량으로 페블러스가 검산한 연산비다. 자율주행 블루프린트에 다른 서버 구성이나 가동 시간을 썼다면 2.66달러가 맞을 수 있다. 발표와 GitHub 저장소에서는 그 설명을 찾지 못했다. ANYbotics 수치는 Encord 원문의 표와 본문에서 가져왔고, 원 평가 자료는 공개되지 않았다.

합성데이터 연재의 다른 글은 연재 허브에 모여 있다.
