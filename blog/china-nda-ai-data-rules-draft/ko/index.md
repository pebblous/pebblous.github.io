# 중국 국가데이터국 AI 학습 데이터 초안… 파생 데이터도 허용

_AI 학습에 써도 되는 데이터를 정한 12개 조치, 원본을 가공해 새로 만든 데이터도 허용하고 데이터에 값을 치르도록 권고_

## Executive Summary

> [!callout]
> 중국 정부가 AI 학습에 쓸 수 있는 데이터의 범위와 그 값을 치르는 방식을 행정 문서 초안으로 내놓았다. 중국 국가데이터국 종합사(国家数据局综合司)는 「데이터 규칙을 정비해 AI 혁신 발전을 돕는 약간의 의견」(《关于完善数据规则 赋能人工智能创新发展的若干意见》) 공개 의견수렴안을 공고하고 12월 6일까지 의견을 받는다. 초안은 3개 부문 12개 조치로 이뤄져 있다.

> 초안은 합법적으로 얻은 데이터와, 전문 지식으로 가공해 내용·형식·구조를 실질적으로 바꾸고 가치를 뚜렷이 높인 파생 데이터(衍生数据)를 AI 학습·추론에 쓸 수 있게 했다. AI 기업에는 구매와 데이터 맞교환, 모델과 데이터의 교환으로 양질의 데이터에 값을 치르도록 권했다. 데이터 출처와 권한 증빙을 기록해 두라는 권고, 데이터 품질 측정·인증 체계, 데이터 오염 공격(포이즈닝)·조작·날조 방지도 함께 담겼다.

> 파생 데이터를 가르는 세부 지침은 초안이 앞으로 연구하겠다고 적은 과제로 남아 있다. 학습 데이터를 쓰는 기업에는 어떤 데이터를 어디서 어떤 권한으로 받았는지 남기는 기록이 사후 책임을 가르는 근거가 된다.

### 주요 수치

아래 세 수치는 공고 원문에 적힌 기간과 항목을 그대로 센 값이다. 값을 치르는 방식과 막겠다는 행위는 원문이 둘 다 끝에 "등"(等)을 붙여 열거했으므로, 넷과 다섯은 초안이 이름을 댄 것만 센 수다.

## 중국 국가데이터국, AI 데이터 규칙 12개 조치 초안 공개

국가데이터국 종합사는 11월 26일자 공고로 이 의견수렴안을 공개했다. 의견은 12월 6일까지 전자우편(zhidujianshechu@nda.gov.cn)으로 받는다. 공고 전문은 중국 매체 펑파이신문(澎湃新闻)의 정부 계정에 11월 27일 실렸고, 21세기경제보도(21世纪经济报道)와 법률 전문 매체 MLex도 같은 초안을 보도했다.

초안의 12개 조치는 세 부문으로 나뉜다. 첫 부문은 학습에 쓸 수 있는 데이터의 범위를, 둘째 부문은 데이터를 주고받는 당사자의 권한과 대가를, 셋째 부문은 거래 뒤의 책임과 안전을 정한다.

| 부문 | 조치 | 주요 내용 |
| --- | --- | --- |
| 합법 취득 데이터의 AI 학습·추론 이용 지원 | 1~4 | 데이터 재산권 제도 적용, 기업이 경영 중 모은 데이터 이용, 파생 데이터 이용, 계약으로 얻은 데이터 이용 |
| 관련 주체의 권익을 법에 따라 평등하게 보호 | 5~7 | 위탁받은 처리자의 권한 범위, 양질의 데이터에 값 치르기, AI 산출물 위험 관리 책임 |
| 데이터 유통 책임 인정과 안전 관리 정비 | 8~12 | 품질 측정·인증, 등록 증빙 기반 책임 규칙, 분쟁 해결과 출처 기록, AI로 데이터 관리 문제 해결, 데이터 안전 |

출처: 국가데이터국 종합사 공고 원문(澎湃新闻 게재)을 페블러스가 요약·번역. 부문 이름은 원문 소제목을 옮겼다.

이 문서는 공개 의견수렴안이라 확정된 정책은 아니다. 의견 수렴 뒤 최종안이 언제 나올지는 공고에 적혀 있지 않다.

## 국가데이터국 초안의 파생 데이터 조건, 실질적 변화와 가치 상승

초안 제1부문은 기업이 이미 손에 쥔 데이터를 학습에 쓰는 길을 넓힌다. 2항은 스마트 기기나 클라우드 서비스에서 생기고 제공자가 권한을 받아 모은 데이터를 기업이 얻거나 복사·이전할 권리가 있다고 적었다. 기업은 그 데이터를 직접 쓰거나 다른 기업에 넘겨 AI 학습·추론에 쓰게 할 수 있다.

3항이 파생 데이터를 다룬다. 원문은 파생 데이터를 "전문 지식을 활용한 가공, 모델링 분석, 핵심 정보 추출 등으로 데이터의 내용·형식·구조 등을 실질적으로 바꿔 데이터 가치를 뚜렷이 높여 만든 데이터"로 정의한다. 단순 복제나 형식만 바꾼 재포장은 이 정의에 들지 않는다. 조건을 갖춘 파생 데이터는 직접 쓰거나 남에게 제공해 AI 학습·추론에 쓸 수 있다.

무엇이 "실질적 변화"이고 얼마나 올라야 "뚜렷한 가치 상승"인지는 초안에 기준이 없다. 3항은 "파생 데이터 인정 규칙 지침을 연구해 세분화한다"(研究细化衍生数据认定规则指引)고만 적었다. 누가 인정하는지도 아직 정해지지 않았다.

4항은 계약으로 얻은 데이터를 다룬다. 등록된 데이터를 사서 AI에 쓰는 것을 지원하고, 표준 유통 계약서 보급을 추진한다. 계약에 데이터 용도가 적혀 있지 않으면 기업은 법을 어기지 않고 남의 권익을 침해하지 않는 범위에서 그 데이터를 직접 쓰거나 남에게 제공해 학습·추론에 쓸 수 있다.

## 구매·以数换数·模型换数据, 국가데이터국이 꼽은 값 치르는 방식

6항은 AI 기업이 데이터 부서를 꾸리고 데이터 투자를 늘리도록 지원한다고 적었다. 값을 치르는 방식으로는 "합법 수집, 협의 구매, 데이터 맞교환(以数换数), 모델과 데이터 교환(模型换数据) 등"을 들었다. 데이터 맞교환은 데이터를 주고 다른 데이터를 받는 거래이고, 모델과 데이터 교환은 데이터를 받는 대가로 모델을 제공하는 거래다.

같은 항은 창작자 쪽도 언급한다. AI 기업이 창작자에게 이익을 되돌려 주는 장치를 강화하고 중장기 이익 협력 체계를 모색하도록 권했다. 이익을 얼마나, 어떤 방식으로 나눌지는 적혀 있지 않다.

5항은 위탁받아 데이터를 처리하는 업체의 권한을 좁혔다. 위탁받은 처리자는 법이나 계약에 달리 정하지 않는 한 그 데이터에 대한 보유권·사용권·경영권을 갖지 않는다. 위탁한 쪽의 명시적 권한 부여가 있어야 그 데이터를 AI 학습·추론에 쓰거나 제공할 수 있다. 클라우드나 데이터 처리 대행 업체가 고객 데이터를 자기 모델 학습에 쓰려면 고객의 명시적 허락이 필요하다는 조항이다.

## 데이터 재산권 등록 증빙, 산 쪽의 과실 판단 근거로

9항은 데이터가 거래된 뒤 문제가 드러났을 때 책임을 어떻게 나눌지 다룬다. 초안은 데이터 재산권 등록 증빙(数据产权登记凭证)을, 데이터를 산 쪽이 합리적 주의 의무를 다했는지와 주관적 과실이 있었는지를 판단하는 고려 요소로 삼는 방안을 모색한다고 적었다. 등록된 데이터를 산 기업은 나중에 그 데이터에 문제가 생겨도 이 증빙을 근거로 책임을 줄이거나 면할 여지가 생긴다.

같은 항에는 이미 만든 모델에 관한 문장이 있다. 기업이 얻은 데이터로 모델을 만든 뒤 그 데이터에 합규 문제가 발견되더라도, "법에 따라 상응하는 책임을 지고 법률 규정을 어기지 않는 경우" 모델 성과에 대한 권익을 계속 누릴 수 있다. 학습 데이터의 하자가 곧바로 모델 권리의 상실로 이어지지 않는 구조다. 이 조건은 책임을 지는 것이고, 앞 문장의 합리적 주의 판단과는 따로 적혀 있다.

10항은 분쟁 조정·중재·공증 체계를 갖추고, 데이터 처리자가 "데이터 출처, 권한 증빙, 처리 과정 등을 기록·보존해 출처를 검증할 수 있고 사용 과정을 추적할 수 있게" 하도록 권했다. 9항의 책임 판단은 이런 기록이 남아 있어야 작동한다. 출처와 권한 증빙을 남기지 않은 기업은 사후 분쟁에서 합리적 주의를 다했다고 보여 줄 근거가 약하다.

## 국가데이터국 초안의 데이터 품질 인증과 포이즈닝 방지 조항

8항은 데이터 품질을 다룬다. 초안은 "업종별·상황별 데이터 품질 측정·인증 체계를 세우고, AI 응용을 위한 데이터 품질 측정 표준을 정비하며, 여건을 갖춘 기관의 데이터 품질 측정을 지원한다"고 적었다. 측정 항목이나 인증 주체는 정해지지 않았다.

12항은 데이터안전법과 개인정보보호법에 따라 AI 데이터 안전을 강화하고, 데이터 포이즈닝(数据投毒)·데이터 조작·데이터 날조·규정 위반 캐싱·규정 위반 국외 이전 같은 악의적 파괴 행위를 막는다고 적었다. 포이즈닝은 학습 데이터에 일부러 잘못된 표본을 섞어 모델을 오작동하게 만드는 공격이다.

7항은 AI 서비스 제공자에게 해로운 산출물과 권리 침해를 막을 합리적 조치와 신고 창구를 요구한다. 합리적이고 필요한 조치를 하지 않아 공익이나 남의 권익을 해치면 법에 따라 책임을 진다. 법적 요구를 이행한 뒤 취한 조치는 책임을 줄이거나 면하는 사실 근거가 될 수 있다고 같은 항에 적혀 있다. 11항은 표준 불일치나 데이터 분산 같은 데이터 관리 문제를 AI 기술로 푸는 것을 장려한다.

## 페블러스가 이 소식을 주목하는 이유

미국에서는 뉴욕타임스가 2023년 12월 OpenAI와 마이크로소프트를 저작권 침해로 제소한 사건처럼, 학습 데이터를 어디까지 쓸 수 있는지가 법원에서 다퉈지고 있다. 이번 초안은 합법 취득 데이터의 학습 이용과 데이터 대가 지급을 정부 문서에 먼저 적었다. 초안이 확정되면 중국 기업이 학습 데이터를 쓰는 조건은 판결보다 행정 규칙과 계약서, 등록 증빙에서 먼저 정해진다.

한국에서는 개인정보보호위원회가 11월 23일 개인정보 보호법 AI 특례 시행령 개정안을 입법예고했다. 원본 개인정보를 학습에 쓰려면 책임자 지정, 내부관리계획, 접근권한 통제, 파기를 갖추도록 한 안이다(「[개인정보 보호법 AI 특례 시행령 예고… 원본 데이터 사용 요건 공개](/blog/korea-pipa-ai-exception-enforcement-decree/ko/)」). 대상은 개인정보로 다르지만, 두 문서 모두 학습 데이터를 쓰는 기업에 어떤 데이터를 어떤 권한으로 썼는지 남겨 두라고 요구한다. 중국 정부는 10월에 학습 데이터를 공급하는 국유기업 국가데이터그룹도 세웠다(「[중국 국가데이터그룹, AI가 배울 데이터를 나라가 공급한다](/report/china-national-data-group-ai-training-data-2026-10/ko/)」). 국가데이터그룹은 데이터를 공급하는 회사이고, 국가데이터국은 규칙을 정하는 행정기관이다.

페블러스는 AI 학습 데이터의 품질을 측정하고 진단하는 일을 한다. 초안 8항의 업종별 품질 측정·인증 체계와 3항의 파생 데이터 인정 기준은 둘 다 데이터를 측정해 판정하는 일이다. 가공으로 "가치를 뚜렷이 높였다"는 주장은 가공 전후의 품질을 측정한 기록이 있어야 입증할 수 있다.

조문 내용은 펑파이신문에 실린 국가데이터국 종합사 공고 원문에서 확인했다. 21세기경제보도와 MLex 기사는 원문에 접근하지 못해 검색 요약으로만 대조했다. 인용한 조문은 페블러스가 우리말로 옮긴 것이다.
