(주)페블러스 데이터 커뮤니케이션팀 · English

탠저블 데이터는 데이터를 만질 수 있게 하는 페블러스의 시도다. 표와 그림으로 읽던 것을 손으로 고르고 돌리고 눌러 보게 한다.

이 시도에는 두 손이 있다. 하나는 Tangible Data Story, 연구 데이터를 독자가 직접 탐색하는 데이터 저널리즘 기사다. 다른 하나는 Tangible Data Art, 페블러스 데이터 아트랩(DAL)이 데이터를 감각의 경험으로 옮기는 작품이다. 기사는 정확성과 출처로, 작품은 경험과 질문으로 같은 데이터를 다르게 만지게 한다.

두 갈래는 읽는 규칙이 다르다. 그래서 이 허브는 둘을 한 지붕 아래 두되 섞지 않는다. 기사 쪽은 실측과 합성을 구분하고 출처와 한계를 함께 적는다. 작품 쪽은 전시와 상호작용의 기록이다.

Tangible Data Story

연구하면서 만든 데이터 탐색기를 기사 안에 그대로 여는 데이터 저널리즘. 화면의 사진·좌표·수치는 실제 측정값이고, 원리를 보여 주려고 만든 합성 예제는 그렇다고 표시한다. 실험 하나가 끝날 때마다 한 편씩 더한다.

실측과 합성을 구분해 둔다

사진·좌표·이웃·층별 값처럼 실제로 측정한 것과, 원리를 보여 주려고 수학으로 만든 예제를 화면에서 따로 표시한다. 둘을 섞어 읽지 않도록 매 편에 같은 규칙을 쓴다.

가까워 보인다는 인상에서 멈추지 않는다

점이 가까이 모였다고 해서 모델이 그 이유를 안다는 뜻은 아니다. 어떤 표현과 거리로 계산했는지, 어떤 규칙으로 골랐는지 되짚을 수 있게 출처와 계산 경로를 함께 둔다.

데이터는 내려받을 수 있다

각 기사는 화면에 쓴 데이터 파일과 출처 목록을 함께 공개한다. 독자가 같은 자료로 다른 질문을 던질 수 있어야 만질 수 있는 데이터다.
