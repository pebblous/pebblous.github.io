(주)페블러스 데이터 커뮤니케이션팀 · English

탠저블 데이터는 데이터를 만질 수 있게 하는 페블러스의 시도다. 표와 그림으로 읽던 AI 데이터의 세계를 손으로 고르고 돌리고 눌러 보게 한다. 갈래는 둘이다. Tangible Data Story는 연구 데이터를 독자가 직접 탐색하는 데이터 저널리즘 기사이고, Tangible Data Art는 페블러스 데이터 아트랩(DAL)이 데이터를 감각의 경험으로 옮기는 작품이다. 기사는 정확성과 출처로, 작품은 경험과 질문으로 같은 데이터를 다르게 만지게 한다. 이 허브는 둘을 한 지붕 아래 두되 섞지 않는다.

Tangible Data Story

연구하면서 만든 데이터 탐색기를 기사 안에 그대로 연다. 화면의 사진·좌표·수치는 실제 측정값이고, 원리를 보여 주려고 만든 합성 예제는 그렇다고 표시한다. 실험 하나가 끝날 때마다 한 편씩 더한다.
